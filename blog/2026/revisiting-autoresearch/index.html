Revisiting Recent Trends in Self-Improving Agents for Autoresearch

LLM agents work on one problem, using evaluation feedback to search for the best solution within a fixed evaluation budget.

Chonghe Jiang5 min read
On this page Methods Takeaways What’s next?

Methods

Takeaways

These papers highlight two ways to improve research agents: refresh their context, or train the roles that decide what to investigate next.

What’s the Next Step?

I see evaluation time as a major constraint on self-improving research agents. A promising idea still needs to be tested, and those tests can dominate the research budget. In DuoDiscover’s vLLM study, one full evaluation takes about 85 minutes. This points to two directions.

Use fewer evaluations

How can we find a better solution with fewer calls to the evaluator? Training-free methods can use past results to select more informative experiments and avoid repeating failed attempts. With training, a research policy can learn which directions are worth pursuing. Both aim for sample-efficient search: reaching a stronger verified result within a fixed evaluation budget.

Memento 3 offers a training-free example. The agent turns interaction feedback into a revisable handbook of environment rules, then compiles those rules into an executable world model. It checks the model against past observations and uses it to plan future actions. The LLM stays frozen; the handbook and simulator improve as evidence accumulates. This illustrates an algorithmic route to fewer real interactions: use what the agent has learned to guide its next attempt.

Make evaluations cheaper

Can a cheap approximation tell us which candidates deserve a full evaluation? Smaller test suites, shorter runs or surrogate models could make it possible to explore more candidates with the same resources.

DuoDiscover offers an example: agents develop optimization targets together with cheap, tailored proxy evaluators. They search using these proxies, then confirm improvements with the full evaluator. Fidelity tests also check whether proxy rankings still agree with full evaluations as the search progresses.

Working on self-improving agents, I’m always interested in the models people choose and the tasks they test them on. Some familiar tasks, such as Erdős problems and packing benchmarks, already seem close to saturation.
