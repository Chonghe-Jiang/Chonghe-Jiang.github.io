Revisiting PPO for LLM Post-Training

PPO and related policy-gradient methods for LLM post-training.

Chonghe Jiang9 min read
On this page Recent work Models & Tasks

This post reviews PPO and related policy-gradient methods for large language models.

Review of Recent Work

Where the papers intervene

Reward centering changes the advantage. Score centering changes the log-probability gradient; below, $w$ denotes its importance weight. A frozen LLM can replace learned value estimates, while an auxiliary prediction loss can add supervision without estimating values at all.

Work RL setting Component What changes
SAO Agent Rollouts · GAE · updates One rollout per prompt, asynchronous collection, skip-observation GAE, strict token masking, and more frequent critic updates.
FlashREINFORCE Both Rollouts · baseline Uses $R_i-\bar R_{\mathrm{batch}}$, sequence admission and per-trajectory averaging. No learned critic or $L_V$.
TEMPO LLM Value feedback Uses $V(y_{\mathrm{complete}})-V(s_t)$ on unlabeled questions, with periodic critic recalibration on labeled data.
AC2 LLM Chunk values · advantages Uses $v_i-\bar v$ and critic target $\bar v$. For critic-ready problems, unfinished chunks receive $v_i=V(s\cdot c_i)$.
Score Centering LLM Actor gradient Centers the weighted score: $w\psi_\theta-c(s)$, with $\psi_\theta=\nabla\log\pi_\theta$ and $c(s)=\mathbb E_{a\sim\mu}[w\psi_\theta]$. Addresses drift from training–inference mismatch.
Decoupled PPO LLM¹ Probability ratios Separates behavior correction $\nu/\mu$ from clipping around $\pi_\theta/\nu$, where $\nu$ is a recent proximal policy.
EasyPPO Both Critic weighting · updates Uses $\omega_x\propto1/\max(\hat\sigma_x,\varepsilon)$, retains truncated samples for the critic, filters them for the actor, and uses smaller critic minibatches.
BPCO LLM Critic · GAE · clipping Bounds values to the reward range, uses $Y_t=R$, preserves raw advantages, and adapts $\lambda_\pi$ to length. Optional privileged critic inputs; Divergence PPO clipping.
LVRL Agent Value estimates · step credit A frozen LLM uses trajectory and group context to estimate values. Anchored value differences give action-level advantages; no critic optimization.
CoPE Agent Auxiliary policy loss Adds successful-trajectory action forecasting to GRPO on a shared backbone. It changes supervision, without adding a value critic.

¹ Decoupled PPO refers to the linked GSM8K example. AC2’s chunks divide a proof into segments, without external interaction.

BPCO: change what the critic learns

BPCO separates the actor’s bootstrapping from the critic’s target: $\lambda_V=1$ keeps the target tied to the observed reward, while $\lambda_\pi(L)=1-1/(\alpha L)$ adapts credit propagation to response length. Its bounded head prevents impossible return predictions. An optional reference answer or rubric helps the critic during training without entering the policy’s prompt. Its Divergence PPO uses a token-probability-dependent clipping range; this is distinct from Decoupled PPO above.

LVRL: redistribute the outcome across actions

LLM Value Functions for Credit Assignment in Agentic RL uses a frozen LLM to read completed trajectories, with other rollouts providing policy context. At the environment-action level, it anchors $\tilde V_0=\bar R_G$ and $\tilde V_T=R$, then computes

\[\bar A_t=\tilde V_{t+1}-\tilde V_t, \qquad \sum_{t=0}^{T-1}\bar A_t=R-\bar R_G.\]

It divides these differences by their group-wide step standard deviation; every token in an action shares that action’s advantage. The unnormalized sum is fixed by outcomes, but the LLM determines where credit goes. These are hindsight estimates, not an ordinary prefix-only value function. Anchoring preserves the total signal; it does not guarantee correct local credit.

CoPE: learn more from successful trajectories

CoPE keeps GRPO and adds a forecasting loss. From history $h_t$, the shared backbone predicts the next $K+1$ actions recorded in a successful rollout:

\[L_{\mathrm{AF}} =-\mathbb E_{\tau\mid\mathrm{success}} \left[\sum_t\log p_\theta(a_{t:t+K}\mid h_t)\right].\]

Training minimizes $L_{\mathrm{GRPO}}+\eta L_{\mathrm{AF}}$, averaging the forecasting term over successful rollouts within each group. A forecasting instruction distinguishes $p_\theta$ from the acting distribution, even though they share parameters. At inference, the agent still acts one step at a time. The added signal teaches which action sequences followed successful histories, rather than how much scalar value each history had.
